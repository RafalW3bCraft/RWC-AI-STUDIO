## Overview

RWC Bot Studio is an advanced, Google Colab–ready FastAPI application for AI-powered image generation and conversational intelligence. It combines state-of-the-art vision models (Stable Diffusion), advanced conversational agents (DialoGPT), and prompt refinement (GPT-2), all orchestrated via a robust FastAPI backend with a modern HTML/CSS frontend.

**Key Features**
- **AI-Driven Image Generation**: Customizable styles and parameters using Stable Diffusion.
- **Conversational AI**: Natural dialog via DialoGPT.
- **Prompt Refinement**: Intelligent prompt enhancement with GPT-2.
- **Integrated Frontend**: Responsive web UI, seamless Colab/Ngrok deployment.
- **Secure Feedback & History**: Per-session memory for chats and images, feedback endpoint for ratings/comments.
- **Colab & Edge-Ready**: Runs fully in Google Colab (free tier, with GPU/T4 support).
- **No Auth Required**: Default configuration is open access with session memory and secure token handling.

## Usage

### 1. Launch in Colab
Open the notebook in Google Colab and run all cells to set up the environment and dependencies. Make sure to select GPU runtime for best performance.

### 2. Mount Google Drive
The notebook automatically mounts Google Drive for persistent storage of generated images:
```python
from google.colab import drive
drive.mount('/content/drive')
```
All images generated by the bot are saved to `/content/drive/MyDrive/rwc_bot_images` for easy export and sharing.

### 3. Install Dependencies
All required packages are installed via pip:
```python
!pip install --quiet fastapi uvicorn[standard] pyjwt pydantic torch torchvision diffusers transformers accelerate pillow aiofiles httpx nest_asyncio pyngrok pydrive2 pydantic-settings passlib bcrypt
```

### 4. Start the Backend
The FastAPI app launches via Uvicorn. ngrok is used to generate a public URL for external access:
```python
import uvicorn
from pyngrok import ngrok
# ... full server setup in notebook code
```

### 5. Access the Web Interface
Once running, the notebook prints an ngrok HTTPS URL. Open this URL in any browser to launch the fully integrated RWC Bot Studio interface (mobile responsive HTML/CSS/JS).

### 6. Chat & Create
- **Image Generation**: Select style, specify a creative prompt, tweak parameters, and click send.
- **Dialog**: Switch to chat mode and interact with the bot using natural language.
- **Feedback**: Rate and leave comments via the Feedback endpoint after each creation.

## Setup

### Prerequisites
- Google Colab account
- Google Drive (for image storage)
- GPU runtime enabled (recommended: T4)

### Steps (Colab Compatible)
1. **Upload Notebook:** Open RWC_Bot_Studio.ipynb in Google Colab.
2. **Run All Cells:** This installs packages, mounts Drive, sets up models, and launches the server.
3. **Ngrok Setup:**
   - Optionally provide an Ngrok token via secrets for custom tunnels.
   - Defaults to free-tier anonymous tunnel if no token is provided.
   - The notebook prints the public URL for the running bot.
4. **Access the Interface:** Use the printed URL to reach the FastAPI-powered frontend.

### Key Python Packages
- `fastapi`, `uvicorn`, `diffusers`, `transformers`, `torch`, `pydantic`, `pyngrok`, `pydrive2`, `passlib`, `pydantic-settings`, etc.

## System Design & Architecture

- **Backend**: FastAPI with endpoints for chat (`/chat`), image generation, feedback (`/feedback`), and file serving (`/drive/{imgfile}`).
- **Frontend**: HTML/CSS/JS (rendered using FastAPI's HTMLResponse), responsive, interactive UI.
- **Session Management**: Per-user in-memory chat/image history (anonymous by default, no authentication required).
- **Security**: JWT tokens and passlib, bcrypt for safe handling if user auth is extended.
- **File Handling**: All generated images are stored persistently to Google Drive and accessible via file serving endpoints.
- **Ngrok Integration**: Automatic tunnel creation for external web access.

## Configuration

### Model Selection
- **Stable Diffusion**: `Lykon/DreamShaper` (customizable via settings)
- **Conversational AI**: `microsoft/DialoGPT-medium`
- **Prompt Refinement**: `gpt2`

#### Advanced Settings
All parameters can be extended in notebook code (see the `Settings` class).
- `DEVICE`: auto-selects CUDA (GPU) if available, else CPU
- `MODEL_ID`: change to any HuggingFace-compatible Stable Diffusion model
- `JWT_SECRET_KEY`, etc., for authentication extensions

### Environment Variables
- `HF_TOKEN`: Optional HuggingFace token if using gated models
- `NGROK_TOKEN`: For ngrok authentication (recommended for production/public URLs)

## API Reference

### `/chat` (POST)
- **Type**: "image" or "chat"
- **Fields**:
  - `prompt` (string): Text prompt for generation or chat
  - `style` (string): Image style ("fantasy", "cyberpunk", "anime", "oil")
  - `num_inference_steps`, `guidance_scale`, etc.: Advanced image generation parameters
- **Returns**: Image and/or bot reply, generation time, history

### `/drive/{imgfile}` (GET)
- Serve generated images from Google Drive

### `/feedback` (POST)
- Submit ratings/comments for prompts and images

## Troubleshooting & Tips

- **GPU Required**: For best performance, ensure Colab notebook is set to GPU.
- **Ngrok Rate Limits**: For heavy/production use, set a custom Ngrok token.
- **Model Access**: For gated HuggingFace models, set `HF_TOKEN` via Colab secrets.
- **Image Storage**: Images are auto-saved to Colab Drive, accessible after each run.
- **Logs & Debugging**: All progress and error logs are printed to Colab console.
- **Notebook Environment**: Some endpoints/features may differ if run outside Colab; for best results, use as intended in Colab.
